# 🌐 ZL90 Router

![ZixLink logo](include/logo.png)
[![Manufacture](https://zixlink.ru/)](#)

Высокопроизводительный промышленный роутер, разработанный для обеспечения надежной связи, интеграции IoT-устройств и автоматизации технологических процессов (АСУ ТП). Поддерживает резервирование каналов связи и работу в жестких эксплуатационных условиях.

---

## 🛠 Ключевые характеристики (Hardware)

Устройство оснащено полным набором современных сетевых интерфейсов и классических промышленных портов:

*   **🌐 3 × Ethernet Ports** — Высокоскоростные порты для локальной сети и подключения к провайдерам (WAN/LAN).
*   **📶 Wi-Fi Module** — Беспроводная точка 2.4/5.8ГГц доступа для настройки и подключения локальных клиентов.
*   **⚡ 4G LTE Modem** — Встроенный сотовый модем с двумя SIM-картами для мобильного интернета и резервного канала.
*   **🔌 USB Host** — Разъем для подключения внешних накопителей, периферии или дополнительных модемов.
*   **🏭 RS-485 & RS-232** — Промышленные последовательные интерфейсы для опроса датчиков, контроллеров (PLC) и работы по протоколу Modbus.

---

## 🚀 Возможности и функционал (Software)

- **Резервирование связи:** Автоматическое переключение между проводным интернетом (WAN) и мобильной сетью 4G при потере сигнала.
- **Промышленные протоколы:** Встроенный шлюз Modbus RTU в Modbus TCP для прозрачной передачи данных от датчиков.
- **Безопасность:** Поддержка VPN (OpenVPN, WireGuard), межсетевого экрана (Firewall) и защищенного удаленного доступа.
- **Удаленный мониторинг:** Поддержка отправки телеметрии по MQTT и интеграции с системами мониторинга (Zabbix, Prometheus).

## 🏁 Быстрый старт

### 1. Подключение к устройству
По умолчанию роутер доступен по локальной сети:
*   **WiFi Точка:** `zl90`
*   **WiFi Пароль:** `1234567890`
*   **IP-адрес:** `192.168.80.1`
*   **Логин/Пароль:** `admin` / `admin`

### 2. Сборка прошивки из исходников
Для компиляции собственного образа выполните команды в терминале:
```bash
# Клонирование репозитория со всеми сабмодулями
git clone --recursive https://github.com/nmacs/zl90
cd zl90

# Сборка Docker-контейнера
cd docker
make build
cd ..

# Сборка проекта
make prepare
make config
make clean
make build_in_docker
```
